# Library Database
- **This project contains SQL examples for designing and working with a library database.**

## Database Components
- Addresses
- Members
- Libraries
- Books
- Authors
- Categories
- Loans

## Relationships
- **The database uses primary keys and foreign keys to establish relationships between tables.**

**Many-to-many relationships are implemented using junction tables such as:**
- `kategori_kitap`
- `kitap_yazarlar`
- `kitap_kutuphane`

## Topics Covered
- Database Design
- DDL
- DML
- Primary Keys
- Foreign Keys
- Table Relationships
- SQL Queries
